Projetos

To-do-list

Aplicação web desenvolvida para gerenciamento de tarefas, permitindo ao usuário adicionar, editar e remover tarefas de maneira simples e intuitiva. O projeto utiliza JavaScript para a manipulação dinâmica da interface e LocalStorage para manter os dados salvos no navegador. Também possui funcionalidades de importação e exportação em formato JSON, permitindo salvar e carregar listas de tarefas. A interface foi construída com HTML e Bootstrap.

Cadastro de Usuários

Aplicação web desenvolvida para cadastro e gerenciamento de usuários, permitindo adicionar, editar e excluir registros contendo informações pessoais e de endereço. O sistema utiliza JavaScript e LocalStorage para armazenar os dados no navegador e possui integração com a API ViaCEP, que realiza a consulta automática do endereço a partir do CEP informado. A interface foi desenvolvida com HTML e Bootstrap, proporcionando uma organização simples e responsiva dos dados.
